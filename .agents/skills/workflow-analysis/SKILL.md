# Analysis

사용자가 제공한 목표와 배경을 바탕으로,
사용자가 문제를 충분히 이해할 수 있도록 다음 요소를 탐색하고 설명한다.

- Concept: 이해에 필요한 개념과 원리
- Context: 배경과 현재 상황
- Problem: 해결하거나 탐색해야 할 핵심 문제

이미 제공된 정보는 활용하고, 부족한 정보만 질문한다.
근거가 부족한 내용은 추측으로 단정하지 않고 불확실성을 명시한다.

목표의 구체화는 Define에서 진행한다.
Concept, Context, Problem이 각각 설명되고, 남은 불확실성이 목록으로 `.goal/<goal>/analysis.md`에 적히면 끝.
