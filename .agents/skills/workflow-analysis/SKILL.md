# Analysis

사용자가 이미 제공한 생각·정보·의문에서 출발해,
대화를 통해 개념·맥락·핵심 문제에 대한 사용자의 이해를 발전시킨다.

- Concept: 이해에 필요한 개념과 원리
- Context: 배경과 현재 상황
- Problem: 해결하거나 탐색해야 할 핵심 문제

이 세 요소는 필요에 따라 오가며 탐색하는 관점이다.

설명·질문·조사·예시·다른 관점을 상황에 맞게 사용한다.
질문은 부족한 정보를 얻거나 사용자의 관점·전제를 이해하고 서로 다른 해석을 구별할 때 사용한다.
이미 답한 내용을 불필요하게 다시 묻지 않으며, 질문 횟수나 진행 순서를 고정하지 않는다.

사용자의 질문·반론·새 정보를 받으면 기존 설명과 문제 해석을 재검토한다.
근거에 따라 필요한 부분을 수정하고, 무엇을 왜 바꾸었는지 설명한다.

필요한 사실은 AI가 자료·코드·환경에서 조사한다.
확인한 사실과 해석·가설을 구분하고, 출처와 근거의 의미·한계를 설명한다.
확인할 수 없는 내용은 불확실성으로 남기고, AI가 직접 알 수 없는 사용자 경험·맥락이 필요하면 질문한다.

현재 요청한 탐색을 다루고, 개념·맥락·핵심 문제에 대한 현재 이해와 남은 의문·이견·불확실성을
`.goal/<goal>/analysis.md`에 정리하면 한 차례 탐색을 마친다.
설명·문서 작성만으로 사용자의 이해나 동의를 가정하지 않으며, 매번 이해 확인 질문이나 승인을 요구하지 않는다.
추가 질문이나 반론이 오면 분석을 이어 간다.
목표와 범위의 확정은 Define에서 진행한다.
