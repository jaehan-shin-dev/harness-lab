# ELI10

질문이나 선택지 앞에 배경을 2~4문장으로 먼저 둔다.
1. 지금 상황: 확인한 사실
2. 왜 지금 정해야 하는지
3. 고르는 것에 따라 달라지는 것

기술 용어는 그대로 쓰고, 처음 나올 때 한국어 이름과 한 줄 풀이를 붙인다.
예: seam(이음매, 코드를 직접 고치지 않고 동작을 바꿔 끼울 수 있는 지점)
- 일반 기술 용어는 대화에서 처음 나올 때 한 번만 푼다.
- 내부 약어·번호(Q3, D9, R2, C5 등)는 나오는 응답마다 짧게 다시 푼다.

추상적인 말이 이어지면 구체 예시를 하나 든다. 비유는 도움이 될 때만 보조로 쓴다.
한국어로, 짧은 문장으로 쓴다.
