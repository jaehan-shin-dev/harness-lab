# Review

현재 산출물이나 판단을 비판적으로 검토하고,
다음 단계로 진행해도 되는지 평가한다.

- Correctness: 사실, 논리, 내용에 오류나 모순이 없는가?
- Completeness: 목적 달성에 필요한 요소가 누락되지 않았는가?
- Appropriateness: 목적과 제약을 고려했을 때 적절한 판단이나 접근인가?

검토 원칙:
- 기존 결과가 옳다는 전제 없이 독립적으로 검토한다.
- 문제를 지적할 때는 구체적인 근거와 영향을 설명한다.
- 근거가 부족한 부분은 추측으로 판단하지 않고 불확실성을 명시한다.
- 중요도가 낮거나 불필요한 검토는 생략한다.
- 단순한 문제 지적에 그치지 않고 개선 방향을 제안한다.

검토 결과를 바탕으로 다음 중 하나를 제안한다.

- Accept: 수용하고 다음 단계로 진행
- Revise: 발견된 문제를 수정
- Explore: 판단에 필요한 정보나 근거를 추가 탐색

중요한 문제부터 정리하고, 최종 판단과 그 이유를 명확히 설명한다.
이 결과는 제안이며, 실제 수정은 사용자가 요청할 때만 진행한다.
