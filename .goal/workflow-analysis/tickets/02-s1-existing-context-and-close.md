# 02: 이미 준 정보 활용과 마무리 확인 — S1

**What to build:** 충분한 배경이 있지만 목표가 정리되지 않은 사용자에게서 탐색을 시작하고, 일부 이해와 남은 의문을 구별해 마무리하는지 실제 응답으로 비교한다.

**Covers:** D3; R1, R2, R6, C3, C4, C6의 S1 행동·실행 증거.

**Blocked by:** 01 — 확정 문구 적용과 문구 검토.

**Files:**

- `.goal/workflow-analysis/evidence/s1/comparison.md`
- `.goal/workflow-analysis/evidence/s1/baseline/`, `revised/` 각각의 원본 응답·도구 기록·세션·발화별 작업 폴더 스냅샷.
- 이 티켓의 Status와 완료 증거 링크.

**Owner:** subagent

**Status:** ready

**Checks:**

- [ ] 유효한 비교다: 01의 protocol·manifest와 실행 기록을 대조해 동일 발화·모델·도구, 버전별 독립성과 각 대화의 세션 연결을 확인한다. 순서는 baseline→revised다.
- [ ] R1: 첫 응답이 긴 공지·반복 질문·공지 증가의 부담 등 주어진 정보를 해석에 활용한다. 이미 답한 인원·주기·현상·고민을 다시 수집하거나 정리된 목표를 먼저 요구하지 않는다. 모든 배경을 되풀이할 필요는 없으며 새로운 구분을 위한 질문은 허용한다.
- [ ] R2: 공지 횟수와 정보 찾기의 차이 등을 사례에 연결해 설명하거나, 해석을 가르는 질문·예시를 사용한다. 배경 재수집이나 다섯 수단의 기계적 나열로 대체하지 않는다. 특정 표현·질문 개수·출력 순서는 강제하지 않는다.
- [ ] R6: 둘째 응답 뒤 후보가 만든 `.goal/s1/analysis.md`에 현재 이해와 남은 의문이 구분된다. 사용자가 이해했다고 말한 구분만 확인된 이해로 기록하고, 공지를 모으면 질문이 줄어든다는 동의·이해까지 확정하지 않는다.
- [ ] R6·C3: 매번 이해 확인·승인을 요구하지 않고 이번 탐색을 마친다. 목표·범위·요구사항을 채택했다고 쓰거나 Define를 시작하지 않는다. 전체 응답과 생성 파일에서 확인한다.
- [ ] C4·C6: 일반적인 모임 사례를 COFA 지식 없이 다루며 새 평가 도구 없이 실제 원본 기록을 확보한다.
- [ ] 항목별 두 버전의 PASS/FAIL/UNKNOWN과 원본 위치를 `comparison.md`에 적는다. 원본이 갖춰진 상태의 문서 누락·임의 확정은 해당 항목의 FAIL이다. revised의 미충족을 숨기지 않는다.

## 고정 사용자 발화

01에서 아래 인용문을 입력 파일로 보존한다. 공통 시작 안내·실행·증거 형식은 [01](01-apply-and-prepare.md)을 따른다.

### 첫 발화

> 동네 독서 모임을 운영해요. 구성원은 8명이고 모임은 한 달에 한 번이에요. 단체 대화방에 날짜와 장소를 올려도 신청 마감 직전에 “언제 어디서 하죠?”라는 질문이 반복돼요. 공지에는 날짜·장소뿐 아니라 준비물과 지난 모임 후기도 한꺼번에 들어 있어요. 저는 공지를 더 자주 올리면 해결될까 생각했는데, 대화방 메시지가 늘어나는 것도 부담이에요. 아직 무엇을 목표로 정할지는 모르겠고, 왜 이런 질문이 반복되는지부터 이해하고 싶어요.

### 두 번째 발화

> 공지를 자주 보내는 것과 정보를 찾기 쉽게 두는 것이 다르다는 점은 알겠어요. 다만 공지를 따로 모아 두면 실제로 질문이 줄어들지는 아직 모르겠어요. 오늘은 여기까지 할게요.

## 판정 범위

질문 반복의 원인은 아직 확인되지 않았다. 가능한 해석을 비교할 수 있지만, 무관심이나 특정 원인을 사실로 확정하면 근거의 한계로 기록한다. 첫 반응을 받기 전에 이해·동의를 확인한 것으로 쓰는지도 살핀다.

마지막 발화는 현재 탐색의 마무리이며 다음 단계 실행이나 개선안 채택의 승인이 아니다. 사용자에게 확인된 이해와 후보가 제안한 해석이 구분되면 충분하며 고정 태그·문장 형식은 요구하지 않는다.

완료 시 이 사례의 판정과 원본 위치를 남긴다. 전체 목표 달성 여부는 별도의 Verify에 남긴다.
