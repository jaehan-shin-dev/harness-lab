# 독서 모임 공지 질문 반복: 상황 분석

## Concept — 왜 공지를 올렸는데도 다시 물을까?

공지의 **전달**과 구성원이 필요할 때 정보를 **찾고 확인하는 것**은 다른 일입니다. 단체 대화방에서는 공지가 다른 메시지에 밀릴 수 있고, 한 공지에 날짜·장소·준비물·후기가 함께 있으면 당장 필요한 날짜와 장소가 눈에 덜 띌 수 있습니다. 마감 직전 질문은 정보를 처음 접하는 순간이 아니라 신청 여부를 결정하는 순간에 생길 수도 있습니다. 또 질문이 단순히 정보를 못 찾았다는 뜻인지, 변경 여부를 확인하려는 뜻인지는 아직 알 수 없습니다.

## Context — 현재 알려진 상황

- 동네 독서 모임은 8명이고 한 달에 한 번 만납니다.
- 운영자는 단체 대화방에 날짜와 장소를 공지합니다. 공지에는 준비물과 지난 모임 후기도 함께 들어 있습니다.
- 신청 마감 직전에 “언제 어디서 하죠?”라는 질문이 반복됩니다.
- 공지를 더 자주 올리는 방안을 생각했지만, 대화방 메시지가 늘어나는 것도 부담입니다.

## Problem — 먼저 이해할 문제

핵심은 **공지가 부족한지**가 아니라, 구성원이 신청할 때 날짜·장소를 왜 바로 확인하지 못하거나 다시 확인해야 하는지입니다. 반복 게시가 도움이 될 수도 있지만, 원인이 정보의 위치나 공지 구성, 변경에 대한 불확실성이라면 메시지만 늘릴 수 있습니다. 지금은 원인을 확인하기 전이므로 해결책이나 목표를 정하지 않습니다.

## 남은 불확실성

- 질문하는 사람이 매번 같은 사람인지, 여러 사람인지?
- 공지를 못 보았는지, 다시 찾기 어려운지, 내용을 보고도 변경 여부를 확인하는지?
- 공지 이후 날짜·장소가 바뀌거나 다른 대화에서 다른 일정이 언급된 적이 있는지?
- 공지가 대화방에서 얼마나 쉽게 찾아지는지(고정, 검색 가능 여부 등), 질문은 공지 후 얼마나 지나서 나오는지?
- 질문이 나온 실제 공지의 길이와 날짜·장소의 배치가 어떤지?

최근 공지와 질문이 오간 사례 한두 건을 보면 가능한 원인을 구분하는 데 도움이 됩니다.
